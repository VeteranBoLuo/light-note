These tiny HEVC/HEIF fixtures were generated for Light Note using ImageMagick
and libheif from two solid color rectangles. They contain no personal photos.
`oriented.heic` has a portrait orientation; `tall.heic` checks that card cropping
does not crop the separate display preview. `primary.heic` also serves as the
production HEIC decode probe. The parent directory’s `sRGB.icc` was generated using
LittleCMS (`ImageCms.createProfile('sRGB')`), for conversion before stripping
embedded metadata. Original uploaded files are never rewritten by this pipeline.
