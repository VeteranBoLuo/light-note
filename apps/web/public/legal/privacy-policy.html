1. 适用范围与运营者

本政策适用于轻笺网站、PWA 与 Android 应用提供的书签、笔记、文件、标签、待办、 AI 辅助、反馈和账号服务。

运营者：待填写与 App 备案、网站备案一致的法定主体名称。 对外服务名称为“轻笺”。联系邮箱：1902013368@qq.com。

我们遵循合法、正当、必要和诚信原则，仅在实现明确功能、安全运营或履行法定义务所需的范围内 处理信息。不同功能需要的信息不同，您可以选择不使用非必要功能。

3. Cookie、本地存储与 Android 本地状态

  • Cookie 或会话标识用于保持登录、识别会话并防止跨站请求等安全风险。
  • localStorage、sessionStorage 和 IndexedDB 可保存界面偏好、临时编辑状态、一次性流程标记与缓存。
  • Android 应用会在设备本地保存已同意的政策版本和时间，用于判断是否需要再次提示；该记录不会因此自动上传。
  • 清除浏览器数据、清除 App 数据或卸载 App 会移除相应本地状态，但不会自动删除云端账号与内容。

权限 用途 运行时敏感权限

5. 委托处理与第三方服务

仅在相应功能需要或您主动选择时，可能涉及以下服务：

  • 华为云对象存储服务：保存您主动上传的云文件、图片与必要元数据。
  • DeepSeek 与阿里云百炼 / 通义千问备用通道：处理您主动提交的 AI 问题及所选上下文，用于生成结果。
  • GitHub OAuth：在您主动选择 GitHub 登录时完成授权认证；GitHub 可能在境外处理相关信息。
  • 高德 IP 定位接口：根据访问 IP 获取省市级粗略区域，用于账号展示和安全风控，不调用设备定位权限。
  • 邮件发送服务：发送验证码、账号与安全通知，处理收件邮箱和邮件内容。
  • Iconify 等图标服务：在您主动搜索或选择在线图标时提供图标检索与资源。

当前 APK 未嵌入统计、广告、推送、支付、地图或社交分享类第三方移动 SDK；AndroidX 为实现基础兼容与 WebView 安全能力的应用内依赖，不独立建立面向第三方的数据账号。

定稿前须逐项补充服务提供者法定名称、公开隐私规则链接、处理目的、信息类型与保存规则，并按实际流量复核。

6. 保存、删除与安全

  • 账号和云端内容通常保存至您主动删除、提出注销或服务依法终止之时。
  • 会话、操作、接口和安全日志按故障排查、安全风控及法定义务所需的最短期间保存，并定期评估是否仍有必要。
  • 临时上传、解析缓存和失败任务会按处理目的完成情况清理；备份中的删除信息会在备份轮换后失效。
  • 法律法规要求留存，或为解决争议、保护安全确有必要的，可在对应期限内隔离保存，期满后删除或匿名化。

我们使用传输加密、访问控制、密码哈希、日志脱敏、权限隔离、签名校验和备份等措施保护信息。 互联网服务无法保证绝对安全；发生可能影响您权益的事件时，我们会依法采取补救和告知措施。

您可以通过产品功能或联系邮箱行使以下权利：

为保护账号安全，我们可能需要核验申请人身份。账号注销会影响登录和云端内容恢复； 正式发布前会进一步补齐产品内自助或人工处理流程及预期处理时限。

8. 未成年人

轻笺面向具备相应民事行为能力的用户，不以不满十四周岁的未成年人为主要服务对象。 未成年人应在监护人指导和同意下使用。若发现未经适当授权处理了未成年人信息，请通过联系邮箱告知， 我们会核验并依法处理。
