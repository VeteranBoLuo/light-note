# 商店、赞助与秋日活动场景

场景来源为用户提供的 HTML 原型内嵌素材及三张 2026-09-10 高清原型图，经内置 ImageGen 编辑。保持原场景构图、透视、紫蓝日光或秋日暖光，不新增物件与 UI。页面标题、价格、按钮与业务信息均由 DOM 渲染；图片只承担装饰，alt 为空。物理纸页和书脊上的装饰字迹随场景保留。

`masters/*-strip-*.png` 保留生成母版。无损 WebP 裁切坐标按 `(x, y, width, height)`：

- 商店底部：`(0, 206, 2170, 338)`。
- 赞助底部：`(0, 194, 2170, 338)`。

桌面顶部由 `commerceScene.less` 按路由加载，底部独立定位且延迟加载，正文增长不拉伸背景。`BrandSceneHero.vue` 使用共享移动断点加载移动裁片，页面不请求 PNG 母版。活动未开放时普通用户不挂载场景；管理员鉴权预览可提前加载。

暗色桌面背景保留较高可见度，仅文字一侧使用局部渐变遮罩；移动场景轻度降低亮度与饱和度。深色卡片上的云匣、礼盒不使用正片叠底，以免与深色表面混合变黑。页面根元素不加图片滤镜。

## 辅助插图与保留母版

云匣、礼盒和侧栏纸页分别从原型的 163 × 90、88 × 70、236 × 70 小图经 ImageGen 重制。母版为 `masters/cloud-object.png`、`masters/gift-object.png`、`masters/store-note.png`，页面资源缩至 800 宽，以 WebP 质量 92 保存。保持淡紫玻璃材质、透视与光照，清理压缩模糊，不新增物件。纸页移除字迹，由 `autumn.reference.storeNote` 的 DOM 文案叠加，支持中英文。礼盒按原始比例展示，不拉满整张卡片。

早期 `masters/{support,store,campaign}.png` 为约 2170 × 725 的独立场景；`masters/{support,store,campaign}-hd.png` 为 1672 × 941 整页场景；`masters/store-detail.png` 为 1670 × 942 的整页细节修复尝试。它们与对应旧裁片保留作历史对照，不代表当前桌面顶部实际加载的分辨率。
