# 从保存一份资料开始

轻笺适合想把网页、笔记和文件集中起来，之后还能找到并继续使用的人。也可以只记待办，不必先整理资料或使用 AI。

[打开轻笺](https://boluo66.top)，注册或登录自己的账号。核心资料管理功能免费使用；AI 和云空间有额度限制，额外资源权益以站内资源商店说明为准。自愿支持与购买资源是不同的入口。

## 试一次：准备一份出行清单

不用先搬进所有资料，先完成一件小事：

1. 在“快速添加”选择笔记，写下标题“周末出行清单”，填入下面几行自己的计划并保存。
2. 看到保存成功后打开结果，确认正文在。也可以在“笔记库”按标题找回。
3. 下次登录同一个账号，在笔记库找到这篇笔记，补充交通或住宿安排；离开前确认保存状态已经完成。
4. 如果还要处理订票，可以另外创建待办。关联笔记、加标签和使用 AI 都是可选操作。

可直接使用的示例正文：

```text
周末出行清单
目的地：待决定
交通：比较两种出行方式
住宿：记下预算与候选地点
下次继续：确定出发时间
```

这是一份供你自己创建的示例，不会自动写入账号。不要把私人证件或其他人的资料放进公开演示。

## 保存后去哪里找

| 保存的内容 | 返回位置 |
| --- | --- |
| 网页书签 | 书签页；也可按名称搜索 |
| 笔记 | 笔记库；按标题打开后继续编辑 |
| 本地文件 | 云空间；按文件名找回，预览支持范围以页面提示为准 |
| 待办 | 待办列表；打开后编辑或完成 |

加入待整理的资料还可以从待整理入口处理；资料没有出现在今日的有限条目里，不代表保存失败。换设备后请使用同一个账号；游客体验内容不等于自己的资料。

## 在电脑浏览网页时随手收

1. 用桌面 Chrome 或 Edge 打开[浏览器扩展介绍页](https://boluo66.top/browser-extension)，从页面进入 Chrome Web Store 安装“轻笺 · 随手收”。
2. 点击浏览器工具栏里的扩展图标，选择“书签”。它会带入当前网页的网址和名称，可以自行修改。
3. 保存时如提示登录，选择网站登录授权或邮箱密码登录，并确认是自己想保存到的轻笺账号。
4. 想先存下来再整理，选择“快速待整理”；想同时处理标签等信息，选择“正式保存”。AI 补全不是保存的必要步骤，生成建议也不等于已经保存。
5. 确认保存成功后点击“在轻笺中打开”。以后可在主站书签页按名称找回；如果提示已有相同网址，打开已有结果即可。

侧栏也能写笔记和上传你主动选择的本地文件。笔记的“带入当前网页文字”由你主动点击，并可能要求当前网站授权；文件上传后要等成功确认，不能仅凭进度条走完就关闭。

手机浏览器不按这套桌面扩展步骤安装。直接打开轻笺网站，把网址粘贴到书签入口，或创建笔记、上传本地文件；也可以把扩展介绍页留到电脑上再安装。

## 卡住时怎么继续

| 情况 | 可以做什么 |
| --- | --- |
| 扩展商店打不开或电脑不允许安装 | 直接使用主站保存网址；设置里的“书签栏收藏”也是桌面轻量入口，具体按页面说明操作 |
| 网站登录授权失败 | 重新发起一次登录；也可尝试扩展中的邮箱密码登录。仍失败时先在主站登录保存，不反复提交同一份资料 |
| 网页需要登录、无法识别或 AI 补全失败 | 手动填写网址、名称和描述后保存书签；这不代表轻笺已保存整篇正文。受限内容不会自动绕过权限读取 |
| 提示保存失败或网络断开 | 先保留输入，恢复连接后按页面提示重试。如果不确定是否已经成功，先在对应列表查找，避免反复新建 |
| 文件部分成功 | 到云空间核对已成功文件，只处理失败项；预览失败不等于文件未上传 |
| 登录后找不到刚保存的内容 | 核对账号、资料类型和当前筛选条件，再按名称搜索；不要直接清空内容或重复导入 |

仍无法解决时，可以在站内反馈或[项目问题页](https://github.com/VeteranBoLuo/light-note/issues)说明发生在哪一步、时间和错误提示。公开反馈中不要贴密码、验证码、会话信息或私人正文。
