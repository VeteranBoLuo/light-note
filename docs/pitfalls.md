# 轻笺踩坑与回归防护

本文只保留已经发生、仍可能复发、且不能从代码或通用规范直接看出的约束。历史现象、排障过程、上线状态、提交号和临时 UI 取舍不在这里重复记录，需要时查 Git 历史。文档职责与写作门槛见 [文档目录](./README.md)。

## 记录原则

- 只有涉及数据正确性、安全、并发、跨端兼容、生产环境差异或跨模块唯一事实源的问题才记录。
- 同一根因合并更新，不为新的表现形式另建条目；普通 UI 微调、一次性需求和已有测试能清楚表达的行为不记录。
- 稳定条目只保留能说明根因的“约束”和可执行的“验收”；调查中的完整证据仍按 `development.md` 记录，结论稳定后再删去过程信息。产品规格放 `architecture.md`，编码规范放 `development.md`，视觉规范放 `design.md`。
- 开发前按模块或错误码全文搜索本文；新增内容优先补进现有条目。

## 数据库、事务与 Schema

### LN-PIT-192：跨历史数据域比较必须统一文本字符集与排序规则

**约束：** 书签、笔记、文件和后建业务表跨域做 `UNION ALL`、`JOIN` 或列间比较时，必须显式转成同一 `utf8mb4` 字符集及 MySQL 5.7 可用的排序规则；新表同时显式声明项目统一排序规则。查询转换优先作用于投影或非索引一侧，不为修一个读接口批量改线上表，也不退回内存拼接。

**验收：** 在真实异构 Schema 上验证跨类型排序、翻页和跨域关联；至少覆盖 `utf8mb4_unicode_ci` 旧表关联 `utf8mb4_general_ci` 新表。遇到 `ER_CANT_AGGREGATE_NCOLLATIONS` 或 `ER_CANT_AGGREGATE_2COLLATIONS` 先查 `information_schema.COLUMNS`。

### 事务提交、唯一键竞争与旁路副作用

**约束：** 多表写入只使用同一个 `connection`。唯一键竞争前不得让事务内的普通配置查询提前建立一致性快照；竞争输家必须用锁定读覆盖全部后续事实读取，或开启新事务读取赢家，因为一次 `FOR UPDATE` 不会刷新同事务后续普通 SELECT 的 `REPEATABLE READ` 快照。受每日上限约束的 `grantExp()` 若复用已有事务，必须在事务的第一次普通读前锁定该用户的成长行，或让该事务使用 `READ COMMITTED`，否则等待并发发放提交后仍可能按旧快照低估当日额度。主事务提交后的成长、通知、图标补全等旁路副作用不得把已成功的请求改写成失败；失败应记录稳定错误并异步补偿。（原 LN-PIT-010、068、079）

**验收：** 覆盖事务前置普通读、并发唯一键竞争、赢家提交后输家读取完整子记录、同用户并发 EXP 发放逼近日上限、主事务成功而旁路失败和客户端重试，确认无空快照、额度穿透、伪失败、重复资产或重复记录。

### Schema 双轨与整数类型比较

**约束：** 排查 Schema 时同时检查 `migrations/*.sql` 与运行时 `ensure*()`；发布前以 Schema 断言为准。新增持久化模型在定名和建表前必须查询实际环境的历史表及列签名，`CREATE TABLE IF NOT EXISTS` 不能代替旧表升级；同名旧表承载不同业务语义时使用新的明确表名与旧数据并存，禁止直接套用新外键、清表或把旧状态强行解释成新状态。MySQL 整数展示宽度不是字段类型，门禁比较应规范化 `int(11)`、`int unsigned` 等表示，不能因显示宽度误报。（原 LN-PIT-187）

**验收：** 同时用空库和带有同名旧表、旧数据的快照执行显式迁移与运行时 ensure 两次，确认新旧数据并存、外键正确且过程幂等；再在 MySQL 5.7 的真实 `information_schema` 输出上运行 `check:schema`，确认真实缺列/缺索引失败、仅展示宽度不同通过。

### 历史迁移必须自包含且只执行一次

**约束：** 人工迁移不能依赖此前脚本已经执行；应从当前旧数据直接计算目标状态并幂等。余额期初、积分策略、知识正文等迁移不得挂回应用启动，也不得用“当前同步时间”伪造历史业务时间。（原 LN-PIT-036、138、154、155、186）

**验收：** 在未执行前序迁移、已执行一次和部分完成三种快照上重跑，结果一致且不会重复记账。

### 本地数据库必须失败关闭

**约束：** 本地、测试和一次性脚本不得以生产地址作为默认值；数据库连接边界统一校验运行环境与主机。远程写入只允许当前任务显式授权的一次性进程开启，不能写回 `.env`。安全探针与实际迁移放在同一 Shell 命令时必须先启用 `set -e` 或使用 `&&`，禁止用换行串联后假设前一条失败会自动阻止后一条；`ALLOW_REMOTE_DATABASE_WRITES=true` 只代表显式放行，不会把 `databaseScope=remote` 变成本地库。（原 LN-PIT-162）

**验收：** 缺少环境标识、测试环境或本地配置远程主机时均在建池前失败；生产显式配置才可启动。一次性迁移先故意让安全探针返回非零，确认后续 SQL 没有执行；`databaseConnectionSafety.test.js` 必须继续覆盖“远程写入已放行但 scope 仍为 remote”。

## API、安全与权限

### LN-PIT-193：字符串枚举必须同步安全字段语义

**约束：** 新增或修改字符串 `sort`、`level`、`action` 等枚举时，同时核对业务校验与安全检测器的“精确方法 + 路由 + 字段路径 + 合法值”。不得按字段名全局豁免，也不得关闭整条路由检测。（合并原 LN-PIT-003、044、132）

**验收：** 每个合法枚举不误报，非法值、错误路由和真正的数值字段仍命中对应规则。

### 安全规则必须理解业务载荷边界

**约束：** 大正文、场景 JSON、Base64 派生资源和 AI 原文不能仅凭关键词或通用长度规则判成攻击；也不能通过放大全局阈值解决。豁免必须绑定请求方法、规范化路由、完整字段路径、载荷形态和业务上限。只作为模型输入的文本不能被当成服务端命令。（原 LN-PIT-132、184）

**验收：** 合法上限内载荷通过；畸形、超限、错误方法、错误路由及真实攻击样本仍被检测。

### 风险滑窗只在越线时记一次事件

**约束：** 扫描、频率等滑窗规则只在从阈值内跨到阈值外时落聚合事件；窗口持续超限不能每个请求重复写事件。业务路由返回的 404 不是未知路径扫描。（原 LN-PIT-185）

**验收：** 连续超限只生成一次事件，窗口恢复后再次越线才生成下一次；业务 404 不累计扫描风险。

### 统计过滤不是产品权限

**约束：** 内部账号过滤只服务运营统计，并覆盖该统计的全部分子、分母、趋势和导出；不能反向成为 AI、存储、成长等产品能力权限。角色、权限与统计口径分别使用各自事实源。（原 LN-PIT-095、151）

**验收：** 同一账号在统计中被一致排除，但产品能力仍按正式权限与额度规则判断。

### LN-PIT-199：停用状态不能冒充正式注销

**约束：** 管理员停用与正式注销都会出现 `del_flag=1`，但只有 `role='deleted' AND del_flag=1` 才是可清理的注销墓碑；不存在的 owner 作为孤儿单独处理。扫描、操作资格和最终物理删除必须复用同一账号清理政策，并在删除事务内再次锁定账号行；仅停用、正常或状态不一致的账号全部失败关闭。治理规则的自动执行风险、人工待处理可见性和业务严重程度彼此独立，不能把 `blocked` 直接解释为严重风险。

**验收：** 覆盖 owner 不存在、正式注销、管理员停用、正常和状态不一致五种账号状态；停用账号在扫描中不产生注销残留候选，历史候选不可执行，治理入口与 Worker 均在任何 `DELETE` 前阻断。图片观察项不进入人工队列，注销任务异常在待处理中心只由任务健康入口展示。

### 认证回跳和移动会话必须覆盖完整生命周期

**约束：** 回跳目标要经过同源白名单校验，并在密码、验证码、OAuth、注册等所有成功出口统一消费。Android/WebView 冷启动恢复旧 Cookie 时，不能覆盖本轮已经建立的新会话。（原 LN-PIT-054、070）

**验收：** 覆盖所有登录方式、恶意外域回跳、冷启动旧 Cookie 晚到和退出后重登。

### 公开分享令牌与阅读计数

**约束：** 分享密钥不进入服务器日志可见的 path/query；浏览器端用 fragment 换取短时票据。目录分享新增页面时重新校验分享范围。访问上限按阅读会话计数，不按刷新次数计数。（原 LN-PIT-057、061、062）

**验收：** 日志、Referer 和分析数据中无原始令牌；刷新不重复计数，撤销、过期和目录内容变化立即生效。

### 第三方身份、订单和 Webhook 不能相互替代

**约束：** OAuth 授权码按透明不定长值处理；身份响应不等于用户资料。Webhook 验签只证明来源，不证明订单归属，仍需用不可变订单用途、服务端订单查询和幂等键核对。没有逐单时间时不生成月榜。（原 LN-PIT-019～023、160）

**验收：** 覆盖超长授权码、资料接口失败、伪造归属、重复回调、订单用途冲突及缺少逐单时间。

## 状态、缓存与异步流程

### LN-PIT-195：结构移动要区分排序与换父级，并失效两侧缓存

**约束：** 右侧卡片/列表只承担移入或移出，不提交同级排序；同级排序由页面树负责。所有改变父级的入口必须消费服务端返回的 `previousParentId` 与 `parentId`，失效原、新父级下的筛选快照和返回位置；旧响应缺父级信息时至少使当前账号列表整体过期。

**验收：** 覆盖单篇、批量、多来源、根层 `null`、标签/搜索变体和账号隔离；移动后直接打开原父级与新父级，均无需整页刷新。

### LN-PIT-194：同一资源对象只保留一个读模型

**约束：** 浏览与 CRUD 面向相同实体、权限和结果集合时，在同一分页读模型上渐进披露操作；空项属于同一库存。只有权限边界、工作流或数据模型确实不同才拆后台页面，兼容参数不得长期保留隐形双模式。

**验收：** 浏览、筛选、空项、创建、编辑、删除与批量操作使用同一数量口径；旧入口只做无状态兼容跳转。

### LN-PIT-196：跨资源编辑器不能复用完整业务列表接口

**约束：** 仅用于勾选关联资源的新增/编辑弹框，必须使用专用轻量读模型，只返回资源 ID、显示名和已选关系。不得复用会生成正文预览、标签聚合、状态角标或分页计数的书签、笔记、文件业务列表接口，也不得为了刷新已下线字段额外请求全量标签。多类只读查询应在服务端连接池并发执行，并继续按 owner 与软删除状态过滤。

**验收：** 新增和编辑弹框各只发一个初始化请求；SQL 不读取笔记正文、不做 `JSON_ARRAYAGG` 或资源状态回填；覆盖空资源、已有关系、标签不存在与账号隔离，并以浏览器确认弹框可在一次请求完成后稳定解除加载态。

### 响应式集合不能在赋值后旁路修改 raw 容器

**约束：** 普通对象赋给 Vue `ref` 后会被转换为代理；后续继续修改赋值前保留的 raw 对象不会经过代理。异步并行结果必须先在未发布的局部容器中汇总，完成后用一个全新的对象或数组引用一次性提交；不得先把容器交给 `ref`，再修改 raw 并把同一引用回写。

**验收：** 并行分区至少覆盖单分区、多分区和部分失败；请求完成后无需额外交互即可渲染每个成功分区，不能只出现标题和“查看全部”而内容为空。

### 跨类型时间线必须由服务端全局排序

**约束：** 多类型搜索和分页列表不能先按类型分别截断再拼接，也不能只在前端对当前页排序。服务端使用白名单排序字段、稳定次序键和统一游标覆盖全量结果。（原 LN-PIT-043、190）

**验收：** 翻页无重复、遗漏或乱序；同一时间值下顺序稳定，切换排序会清空旧游标。

### LN-PIT-197：检索结果与导航对象必须保持产品边界

**约束：** 多模块都使用左侧筛选、中间列表和右侧详情，不代表它们承担同一任务。资源中心的主结果只接收可打开和批量整理的书签、笔记、文件；标签属于筛选条件和主题导航，关键词命中时必须通过独立字段与独立视觉区域返回，不能再次混入资源结果、总数、检查器或批量选择。新增协议采用可选开关，未开启的快捷搜索、资源选择器等既有调用方保持原语义。标签计数复用标签空间的存活资源统计事实源，不另写会把软删除或跨账号关系算进去的简化 SQL。

**验收：** 覆盖空关键词、关键词、标签同名、空标签、软删除关系、账号隔离、单类型筛选、滚动追加和旧调用方；资源列表、分组、总数、检查器和批量操作均不出现标签，标签导航仍显示真实图标及三类存活资源数量，关闭新协议后旧搜索返回结构不变。

### LN-PIT-198：请求层已提示的失败不能在页面层重复 Toast

**约束：** `apiBasePost` 等统一请求层已经负责展示服务端失败消息时，页面捕获异常后只维护页内错误态、重试入口与请求 ID，不得再次弹出同义错误消息。只有请求层明确静默的特殊流程，页面才自行提示；下拉刷新等上层交互若统一处理失败，底层加载函数只抛出错误。

**验收：** 断开接口后分别触发首次加载、按钮刷新和下拉刷新；页面保留错误态及重试按钮，每次失败只出现一条用户消息，旧结果的静默刷新失败不会清空列表。

### 展示值、筛选标识和持久事实必须分离

**约束：** 数量、文案、入口参数等展示值不能充当筛选 ID 或数据库状态。待整理、软删除关系、当前页面等状态从权威数据派生；为恢复保留的关系不能计入活跃资源。跨资源编辑器初始化已选 ID 时必须与当前活跃候选取交集；保存兼容只允许丢弃同一对象原本已有的失效关系，新提交的越权或不存在 ID 仍必须拒绝。（原 LN-PIT-006、104、189、191）

**验收：** 覆盖数量为 0/变化、跨入口进入、回收站恢复和旧关系残留，展示与查询口径一致；带历史失效关系的编辑可正常保存，新伪造的失效 ID 不能借兼容路径写入。

### 精确网址索引不能代替原值复核

**约束：** 书签 URL 的每个创建、导入、恢复、修复和编辑入口都必须同步更新精确哈希；哈希只用于查候选，重复分组与删除前仍按完整 URL 二进制复核并检查当前成员上下文。

**验收：** 覆盖所有 URL 写入口、历史空哈希回填、哈希冲突、成员并发变化和引用阻断；不能误合并不同网址或删除仍被引用的书签。

### 链接健康观测与用户决定必须分层

**约束：** 只有外部服务器明确返回 404/410 才记为疑似失效；DNS、超时和网络错误是未知，不能抹掉同一 URL 的既有观测。用户“标记正常”独立保存，扫描或重置不得清除，只有 URL 变化或用户撤销才失效。全量扫描不得在 HTTP 请求中同步等待，也不得只把状态放在 Node 进程内存；必须使用持久任务、书签快照、租约续跑和有上限的批次并发。

**验收：** 覆盖 404/410、DNS、超时、先疑似后未知、标记正常后复检、系统重置和 URL 变更，列表与统计口径一致；再验证一次提交覆盖当前全部书签、重复提交复用同一任务、Worker 重启后从未完成项续跑，且任一时刻外链并发不超过配置上限。

### 动态网页不可读不能退化成 URL 猜测

**约束：** 网页读取按静态提取、通用页面判型、低权限 Chromium 兜底分层执行，不按域名增加解析分支。Chromium 的主请求、重定向和子资源必须经连接层 SSRF 防护，且不继承后端环境或用户登录态。只有扩展中用户主动授权、捕获 URL 与书签 URL 一致的当前页可见文字可作为登录页证据；其余失败必须在模型调用前结束，禁止用 URL 猜名称、描述或标签。

**验收：** 覆盖标准 HTML、JSON-LD、SPA 空壳、Cookie/reload 挑战、登录表单、渲染后错误页、桌面转移动渲染、私网 DNS/重定向/子资源、浏览器不可用、并发与中止；失败场景不调用 Provider、不扣 AI 额度、不回填推测字段，扩展切换标签页或拒绝权限时不会串用正文。

### 异步请求必须有目标快照和请求世代

**约束：** 复用弹框、草稿恢复、虚拟分页、详情目录切换和上传队列都要绑定发起时的业务目标与请求世代；晚到响应不能覆盖新目标。同一详情路由只切换目标时，已有页面不能先置空回到整页骨架；新详情与首屏关联列表应在同一世代内就绪后原子替换，目录的“当前项”以已展示目标为准，待切换目标只表达忙碌/选中状态。兼容入口需要在路由提交前解析最终详情目标，禁止先挂载已废弃页面再由组件跳转；首屏确需加载态时，骨架必须复刻最终页面的主要栏位与卡片边界，避免加载完成后整页换版。关闭浮层前先复制后续导航所需的普通对象快照，不能等待后再读已重置的响应式状态。（原 LN-PIT-061、159、167、168、181）

**验收：** 快速连续切换目标、从兼容入口首次进入、慢请求、乱序响应、切换失败回退、连续打开关闭和组件卸载后，旧内容在新快照提交前保持可见，页面不闪回废弃页面或整页异构骨架，也无旧数据复活或重复任务。

### 写操作后刷新所有受影响的独立读模型

**约束：** 写接口返回的局部快照只能更新其权威范围，不能覆盖初始化响应中的能力字段；成长、树结构和目录写入后，显式刷新或失效所有受影响的独立读模型，不能假设响应式会自动串联。共享的回顾等读模型还须按账号合并在途请求；写入开始时先作废写前读取，优先用写接口返回的完整权威快照原子替换，但只允许同账号、同业务日期或同会话的回执覆盖当前状态，失败动作与重试也必须绑定同一代快照。若接口只返回局部结果，才先从当前快照移除目标并强制回读，禁止迟到响应把条目复活或把跨日新状态回滚。（原 LN-PIT-027、097、180）

**验收：** 操作后逐一检查看板、详情、目录、能力状态和返回位置，无需整页刷新；多入口并发只复用同账号在途读取，写前旧响应迟到或回读失败时，已成功移除的内容不回跳，也不产生重复全量请求；跨日或切换会话时，前一代的成功回执和失败重试都不能覆盖或操作新快照。

### 静默刷新保留旧数据，轮询状态显式可见

**约束：** 页面隐藏时停止轮询；已有数据后的瞬时失败保留旧快照并提示陈旧状态，不清空页面。筛选变化取消旧请求，轮询和手动刷新不能并发覆盖。（原 LN-PIT-081、090）

**验收：** 覆盖隐藏/恢复、慢请求、断网、恢复、筛选切换和手动刷新；确认无请求风暴和旧响应覆盖。

## 前端布局、浮层与交互

### 路由组件必须有可承接属性的单根节点

**约束：** 被 `RouterView` 注入 class/style 的路由组件不得使用无明确承接者的多根模板；布局属性必须落到真实页面根节点。（原 LN-PIT-188）

**验收：** 开发环境无 extraneous non-props attributes 警告，PC/移动固定顶栏与滚动容器均按路由壳预期工作。

### 移动浮层必须遵循唯一 history 栈

**约束：** `BModal`、`BDrawer` 和全屏预览统一接入 `mobileOverlayHistory`。关闭一层并导航或打开下一层时，等待旧占位出栈；`Escape`、系统返回和遮罩只关闭最上层。（原 LN-PIT-083、149）

**验收：** 首次点击即可进入目标，连续多层浮层逐层返回，不闪回、不穿透、不一次关闭多层。

### Teleport 浮层持续跟随触发器

**约束：** 浮层打开后不能假设触发器静止；滚动、缩放、视口变化、软键盘和异步内容变高时重新定位。最大高度要给上下两侧留出可用预算，浮层内容不得用百分比宽度与父级自动宽度形成循环。（原 LN-PIT-014、055、145、150）

**验收：** 在页面滚动、容器滚动、浏览器缩放、移动键盘开合和加载态切结果态下检查位置、尺寸与焦点。

### 移动全屏页面只有一个滚动所有者

**约束：** 全屏 `BModal`、公开阅读页和长列表明确唯一纵向滚动容器；根应用锁滚动时，独立页面自己承接滚动。不得让内外两层同时滚动，也不得依赖 `sticky` 修补错误的页面高度。（原 LN-PIT-042、052、060、144）

**验收：** PC、移动浏览器和 Android WebView 检查顶部/底部可达、滚动不穿透、锚点定位与系统返回。

### CSS 与 flex 的隐性边界

**约束：** `scoped` 样式不得提前结束根节点 `:global()`；Flex 文本子项必须 `min-width: 0`；CSS 数学函数中的百分比减法显式使用 `calc()`；已渲染富内容不用 `pre-wrap` 再解释源码空白。（原 LN-PIT-016、152、163）

**验收：** 路由懒加载前后样式不泄漏；中英文长文本、窄屏和富文本连续空白不横向溢出。

### 画布坐标必须以真实容器为边界

**约束：** 图谱、关系图等运行时画布只能在尚未完成测量时使用回退尺寸；完成测量后，中心点、半径和裁切安全区必须基于真实容器宽高。不得为移动端画布套用桌面最小宽度，否则视觉中心会落到可视区域外。

**验收：** 以窄屏、桌面及容器尺寸变化三种状态检查中心节点坐标；重置视图后中心点仍位于画布几何中心，边缘节点和标签没有系统性偏向一侧。

### LN-PIT-041：头像框前后景不能共用低层叠容器，复杂 SVG 必须预留出血安全区

**约束：** 头像框统一通过 `AvatarFramePreview` 的设计画布缩放；后景、头像、前景分别建立明确层级，父级不能用宽泛深度选择器改写内部图片。复杂素材的 `viewBox` 要保留旋转、辉光和装饰出血。（合并原 LN-PIT-051、071）

**验收：** 头像不变形，前景可覆盖头像、后景不遮脸；小尺寸、深浅主题和动画极值帧均无裁切。

### 状态不能只靠颜色、阴影或动画表达

**约束：** 选中、错误、暂停、完成等状态同时使用实色描边、图标、文字或明确形状；移动共享渲染基线下仍可辨。异步弹框加载态与结果态保持稳定高度，不能靠整卡变色代替层级。（原 LN-PIT-050、085）

**验收：** 覆盖深浅主题、`light-note-mobile-rendering`、动画关闭、加载/空/错误和键盘焦点。

### 日期和排序值保持原始语义

**约束：** MySQL `DATE` 按日期字符串处理，不能先转瞬时时间再拼日历；日期时间选择器的离散选项不能改写用户输入的原始分钟。重复实例使用稳定唯一键，不共享可能相同的排序值。（原 LN-PIT-009、056、176）

**验收：** 覆盖时区边界、夏令时环境、非五分钟值、同日重复项和零值图表。

## 文件、媒体与 Worker

### 云文件展示名、对象键和记录 ID 必须分离

**约束：** 对象键使用账号命名空间内的随机值；同名处理只改展示名，不删除重建旧记录。确认上传时以 OBS 元数据和稳定 `files.id` 为准，并在事务中校验 owner、目录和容量。（原 LN-PIT-064）

**验收：** 覆盖同名并发、回收站同名、确认重试、OBS 成功但写库失败和正文引用稳定性。

### 上传成功不等于正文插入或本地保存成功

**约束：** 上传、Android bridge 投递和浏览器 click 只代表已受理；正文插入、批量分别下载必须等待各自可确认的终态。编辑位置失效时保留已上传云文件并允许重试插入。（原 LN-PIT-098、146）

**验收：** 覆盖用户切换笔记、光标失效、bridge 失败、浏览器拦截多下载和部分成功，结果逐项可解释。

### 业务压缩必须先于通用上传上限

**约束：** 需要客户端压缩的图片不能先被 `BUpload` 的最终体积上限拒绝；文件体积与像素尺寸分别校验。网页下载体积、解析后正文预算和模型输入预算也必须分层。（原 LN-PIT-011、017、024）

**验收：** 覆盖大像素小文件、大文件可压缩、压缩后仍超限、HTML 很大但正文很小及反向情况。

### Worker 任务不能依赖前端入口或 API 日志

**约束：** 图标补全、文档处理等持久任务由服务端事务后入队并去重，不依赖某个前端入口存活。Worker 诊断使用任务表、租约、重试和稳定错误码，不能用 API 请求日志推断执行结果。（原 LN-PIT-079）

**验收：** 从所有创建入口产生任务；Worker 停机、重启、重复领取和永久失败均可从任务事实解释。

### 一次性脚本不得被实时模块连接挂住

**约束：** 可被 CLI 导入的模块不能在 import 时创建 Redis、定时器等常驻副作用；脚本显式创建并在 `finally` 关闭依赖。（原 LN-PIT-013）

**验收：** 脚本成功、失败和中断后都能自然退出，无残留连接或重复消费者。

## AI 与确定性执行

### 当前轮事实、历史对话和公开引用分层

**约束：** 当前显式材料、历史对话、工具结果和公开引用使用不同边界；公开引用不能自动升级为下一轮材料。历史只能帮助理解表达，不能覆盖当前范围或成为写操作参数。（原 LN-PIT-067、069、108、131）

**验收：** 多轮切换资源、追问、公开引用和历史长对话时，工具范围与最终引用只包含本轮允许的事实。

### 服务端引用校验与业务分析展示分层

**约束：** `grounded_markdown` 的来源与数字引用先由服务端完整生成和校验，不得为了简化界面而在校验前删除。书签、笔记、文件、标签，以及资源中心内对当前或明确选中资源执行的分析，都属于“用户已明确选择材料”的业务分析：通过共用 `showGrounding` 展示策略隐藏来源列表，并只在渲染及保存为笔记的副本中移除数字角标；代码下标、Markdown 链接和脚注定义必须保留。帮助问答只检索受控的公开产品知识，也使用同一展示策略只呈现答案，但服务端 Grounding、越界来源和公开状态校验仍必须完整保留。同一业务入口若分别渲染 PC 与移动端 `AiSkillPanel`，两处必须传递同一展示策略并由契约测试覆盖。搜索问答等开放范围、需要用户核验外部证据的入口继续显示来源。

**验收：** 同一响应在书签、笔记、文件、标签、资源中心资源分析弹框和帮助问答中均不出现 `[1]` 和来源条，保存后的笔记也不含角标；PC 与移动入口表现一致；服务端无来源、越界来源和公开状态门禁仍生效，`arr[1]`、数字链接、脚注和代码块不被误删，真正开放范围的搜索问答仍保留来源。

### 工具参数由服务端权威绑定

**约束：** 已校验的资源 ID、owner、URL、时间范围和执行字段由服务端 Compiler/能力注册表注入，不要求模型抄写。模型产生的参数归一化后必须再次满足工具 Schema；绝对时间由确定性代码计算。（原 LN-PIT-077、114、122）

**验收：** 模型省略、别名、越权篡改、非法枚举、跨时区相对时间均被稳定归一或拒绝。

### 意图路由只有一个最终裁决者

**约束：** 原始历史、多个分类器、URL 正则和提示词不能共同决定本轮执行。确定性入口使用明确 TurnSpec；旧 Planner 仅在未迁移范围内工作。能力关闭要同时切断前端入口、服务端工具、说明文案和知识回答。（原 LN-PIT-085、111、112、117、119、129、134）

**验收：** 同一输入在各入口得到一致能力范围；关闭开关后无隐藏调用或“看似可用”的回答。

### AI 生命周期与账本事实分离

**约束：** 确认、材料、工具运行、产物和最终回答分别建模；工具成功前不提交新焦点，HTTP/SSE 成功不等于业务成功。调用次数按阶段、计费归属和修复原因记账，不能从模型文案或动作级常量反推。（原 LN-PIT-107、109、110、120、141、147）

**验收：** 覆盖工具失败、连接中断、重试、确认取消、部分产物和账本回放；用户看到的终态与服务端回执一致。

### 精确事实不能由模型猜测

**约束：** 计数、分类统计、完整列表、引用数量和执行结果来自查询或结构化结果；模型只负责表述。增强信息不得挤掉用户直接询问的主事实。（原 LN-PIT-099、108、113、115）

**验收：** 空结果、截断列表、多分类和工具不可用时明确说明边界，不用正文关键词或命中片段冒充统计。

### 模型额度在真实调用边界占用

**约束：** 只在即将调用模型时原子占用额度，不能在“可能调用 AI”的业务入口预扣。每日等级额度与永久余额分别展示、按既定顺序扣减；免费解析和隐藏调用也进入统一计费清单。（原 LN-PIT-118、127、139）

**验收：** 前置校验失败不扣额度；重试、备用供应商和多阶段调用账本可解释且不重复扣减。

## 实时系统与聊天室

### 滚动意图必须显式建模

**约束：** 是否跟随新消息由用户滚动意图决定，不能用输入框焦点或单次“近底”阈值推断。首屏异步媒体预留最终高度，图片加载和提及候选变化不得把用户从阅读位置拉走。（原 LN-PIT-012、034、177）

**验收：** 覆盖首屏、向上阅读、输入中、新消息、图片晚加载、软键盘和窗口缩放；只有明确保持在底部的用户自动跟随。

### 实时快照与请求能力分别就绪

**约束：** WebSocket 已收到在线数不代表在线名单请求已经可用；连接、订阅、请求通道和快照各自有就绪状态。发送成功先展示服务端响应，不等待已读或二次刷新。（原 LN-PIT-004、046）

**验收：** 覆盖移动重连、订阅竞态、名单请求失败和发送后刷新，头像字段与在线状态不被旧快照覆盖。

### 已读、撤回与幂等是不同事实

**约束：** 房间阅读位置不能代替逐消息回执；已读游标不能停在不可见撤回消息上。新增消息类型只扩展该类型的规范幂等负载，不能整体升级旧消息指纹导致重复。（原 LN-PIT-033、178）

**验收：** 覆盖撤回、投票、多设备、旧客户端重放和滚动发布；旧消息不重复，新类型可正确去重。

### 完整草稿使用单一状态与版本

**约束：** 正文、附件、提及、引用和上传队列属于同一草稿，不能分散到组件局部状态独立恢复。恢复与清除必须比较草稿版本，不能覆盖用户已经开始的新编辑。（原 LN-PIT-045、167）

**验收：** 刷新、切房间、断网恢复、上传中关闭和多实例打开时，草稿整体一致且无附件重复。

## 成长、积分与资产

### 资产流水必须覆盖所有奖励维度

**约束：** 积分、AI 永久余额、空间和道具分别记账；不能用积分 `delta` 解释非积分奖励。余额接入追加式账本时只登记一次期初，管理员审批必须读取当前权威订单和余额。（原 LN-PIT-049、154、155）

**验收：** 每种奖励、扣减、退款和历史迁移都能从账本重放；重复启动或审批不重复入账。

### 消费幂等、经济版本和免费抽奖分离

**约束：** 商店和抽奖依赖账号级幂等操作、规范负载哈希和经济版本；按钮防重不构成幂等。免费惊喜不推进付费保底，限购资格用独立事实表竞争，永久空间不能因“价格合理”而无限购买。（原 LN-PIT-035、161）

**验收：** 覆盖并发点击、响应丢失重试、版本切换、免费/付费交错和限购迁移。

### 角色不能伪造等级事实

**约束：** 所有角色的等级、额度和特权以 `user_growth.exp` 为唯一事实源；管理员身份不能在展示或业务逻辑中硬编码满级。需要保留历史权益时用一次性可审计迁移固化。（原 LN-PIT-156）

**验收：** 普通用户、历史 Root、新 Root 和管理员预览分别验证等级、AI 额度、存储和抽奖次数。

## 浏览器扩展与构建

### Side Panel 权限与页面草稿绑定当前实例

**约束：** `activeTab` 是一次性用户手势授权，固定 Side Panel 不能长期依赖它；需要持续读取时使用明确 host 权限或要求用户重新触发。持久草稿按窗口/标签页实例隔离，不能复用另一页面的标题和 URL。跨异步边界前完成必须依赖点击手势的 `sidePanel.open()`。（原 LN-PIT-169、172、174）

**验收：** 覆盖切标签、切窗口、浏览器重启、权限拒绝和异步准备，当前页信息不串台。

### Manifest V3 与商店包保持静态可审计

**约束：** 构建产物不得包含 `eval`、`new Function` 或运行时生成代码；商店包不复用带公开 build key 的开发 Manifest。正式名称、权限和版本必须从唯一构建事实源生成。（原 LN-PIT-165、182、183）

**验收：** 对最终 zip 解包静态扫描，并检查商店包名称、权限、CSP、key 和版本；不要只检查源码目录。

## 运维与部署

### 静态目录不能与 SPA 路由形成无入口冲突

**约束：** 新增与页面同名的静态目录时必须提供目录入口或调整 Nginx `try_files`，否则直接刷新可能命中目录并返回 403，而站内导航正常。（原 LN-PIT-066）

**验收：** 对页面路径执行直接访问、刷新和静态资源请求，确认均返回预期内容而非目录响应。

### 第三方连通性以生产主机为准

**约束：** 本机能解析或访问第三方域名不代表生产服务器可用；上线前从实际运行主机验证 DNS、TLS、IPv4/IPv6 和超时，错误日志只保留稳定错误码。（原 LN-PIT-020）

**验收：** 从生产同网络命名空间执行只读探针，并验证失败回退不会阻塞主业务。

### Shell 不会展开环境变量值中的 `~`

**约束：** 私钥、证书和部署路径在读入环境变量后必须显式解析为绝对路径；不能假设 Shell 会再次展开变量值中的波浪号。（原 LN-PIT-142）

**验收：** 在非交互 Shell、CI 和本机终端分别执行路径存在性与权限检查。
