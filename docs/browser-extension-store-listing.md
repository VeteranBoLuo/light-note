### 摘要

把当前网页、随手笔记和本地文件快速保存到轻笺，支持待整理、AI 书签补全与 Markdown。

### 详细说明

轻笺快速添加是轻笺的官方浏览器扩展。它把收集入口放在 Chrome 侧边栏，让你不必离开当前网页，就能把想留下的内容同步到轻笺账户。

主要功能：

- 书签：自动获取当前页网址和名称，可快速加入待整理，也可用 AI 补全描述与标签后正式保存。
- 笔记：支持 Markdown 和无工具栏富文本；你主动授权后，可将当前网页可见文字带入草稿。
- 文件：拖拽或选择多个本地文件上传，支持进度、取消和失败重试。
- 同步：支持邮箱密码或通过轻笺网站登录，内容保存到你的轻笺账户。
- 隐私：仅在你主动选择相关功能时读取当前标签页或当前站点内容，不遍历、保存或出售浏览历史，不常驻网页，也不投放广告。

使用前需要轻笺账号。官网：https://boluo66.top

隐私说明：https://boluo66.top/legal/browser-extension-privacy.html

## 单一用途

让用户在浏览网页时，主动将当前页面书签、自己输入的笔记和自己选择的文件快速保存并同步到轻笺账户。

## 权限说明

| 权限 | 审核说明 |
| --- | --- |
| `sidePanel` | 在 Chrome 原生侧栏中展示扩展的书签、笔记和文件快速添加界面。 |
| `tabs` | 用户进入书签或点击“自动获取”时，只读取当前活动标签页的网址和标题。固定侧栏切换标签页后 `activeTab` 临时授权可能已失效，因此需要 `tabs`；不枚举、不保存其他标签页或浏览历史。 |
| `activeTab` | 用户从工具栏主动打开扩展后，为当前标签页提供临时访问，用于书签流程中尽力读取选中文本。 |
| `scripting` | 仅在用户主动收集书签或点击“带入当前网页文字”时执行受限脚本，读取选中文本或当前顶层页面可见文字。 |
| `storage` | 在扩展私有存储中保存设备会话、主题、语言、未提交草稿和幂等重试状态。 |
| `identity` | 使用 `launchWebAuthFlow` 打开轻笺网站登录中转并接收一次性 `chromiumapp.org` 回调；不读取 Google 账号资料。 |
| `https://boluo66.top/*` | 通过 HTTPS 调用轻笺账号、书签、笔记和文件 API。 |
| 轻笺 OBS 精确域名 | 通过服务端签发的短时地址，上传用户主动选择的文件。 |
| `optional_host_permissions` | 仅在用户点击“带入当前网页文字”时，按当前 HTTP/HTTPS 网站精确 Origin 单独申请；拒绝后仍可手动输入。 |

## 远程代码

选择“否”。扩展不下载或执行远程 JavaScript / WebAssembly；全部可执行代码均打包在 ZIP 内。网络请求只访问轻笺 API、签名文件上传地址和用户主动授权的登录流程。

## 数据使用披露

勾选：

- 个人身份信息：登录邮箱、昵称、账号标识。
- 身份验证信息：密码（仅登录表单内存和 HTTPS 传输）、会话标识、随机设备标识。
- 网站内容：用户主动收集的当前页标题、选中文本和按站点授权后读取的可见文字。
- 网络浏览活动：用户主动收集的当前页网址；不遍历或保存浏览历史。
- 用户生成的内容：书签字段、笔记正文和用户主动选择上传的文件。

不要勾选：健康、财务、精确位置、个人通信、用户活动监测等扩展未处理的数据类型。

有限用途认证全部按真实实现勾选：数据只用于扩展单一用途；不出售；不用于广告、信用评估或无关用途；除政策允许的必要例外外不允许人工读取，也不进行无关第三方传输。

## 测试说明

1. 安装后点击工具栏中的轻笺图标，Chrome 右侧打开原生 Side Panel。
2. 入口不会读取当前网页；选择“书签”后才读取当前活动页的网址和标题。
3. 未登录也可填写；保存时点击登录。可通过轻笺网站自行注册或使用邮箱密码登录。
4. 书签可选择“快速待整理”或“正式保存”；正式保存的 AI 建议只填充表单，不自动保存。
5. 笔记支持 Markdown / 富文本；点击“带入当前网页文字”后才申请当前网站权限。
6. 文件只处理通过系统选择器或拖拽主动选择的本地文件。

若审核要求专用账号，再创建最小权限的独立审核账号；不得在仓库、商店描述或公开截图中保存密码。
